# Contributing

Start from a scoped GitHub Issue/task contract. Follow accepted ADRs and path instructions. Keep PRs small and vertical. Add/modify tests with behavior. Run repository validation commands. Report contract, permission, dependency and security impacts in the PR. Do not include customer data, secrets or inference payloads.

Automerge is permitted only after required checks and repository rules pass. Security vulnerabilities must follow `SECURITY.md`, not public Issues.
